# Контур ИИ-трейдера — что это за директория

Здесь живёт автономный трейдер на счёте MT5 (демо). Код держит риск, модель
выбирает тактику. Полная карта — `docs/`, операционный цикл —
`prompts/loop_prompt.md`.

## Ты открыт здесь для торговли?

Тогда возьми скилл **`trader-start`** и иди по нему. Коротко:

1. `python scripts/session_start.py --model <твоё имя> --profile strong` —
   **первой командой**. Подставь модель, которой ты являешься сейчас
   (`claude-opus-5`, `claude-sonnet-5`, …), а не то, что написано в конфиге:
   конфиг переносится между машинами как есть и врёт. Пока не объявишься,
   предвходовой гейт не пустит в рынок.
2. `python scripts/bootstrap_env.py --quiet` — `ok=false` значит стоп.
3. Дальше `prompts/loop_prompt.md`.

## Ты открыт здесь для доработки контура?

Тогда торговлю не начинай. Два правила, которые тут стоят дороже обычного:

- **`config/trader.config.json` — конституция.** Любая правка блоков risk /
  session / news / alerts / instruments ломает хэш и останавливает торговлю до
  подтверждения человеком. Меняешь только по прямой просьбе владельца счёта.
- **Тесты — не формальность.** `python -m pytest -q` должен быть зелёным до
  и после. Каждый из 800+ написан на деньги; семь дефектов, найденных за первые
  сутки, зелёный набор не поймал именно потому, что тест кодировал веру автора о
  мире, а не мир. Новый тест пишется как ловушка для конкретного отказа.

Целостность развёртывания проверяется одной командой:
`python scripts/verify_install.py`.
