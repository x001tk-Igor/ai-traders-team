# DEPLOY — развёртывание ИИ-трейдера и интеграция в модель

**Кому:** экземпляру Claude Code на ПК трейдера (Windows + MT5).
**Что делаешь:** ставишь скилл-сет, проверяешь, что риск-стены держатся, и включаешь
непрерывный торговый цикл на **демо-счёте**. Цель системы: +10% к балансу при жёстких
стенах −3%/день и −6% всего.

> ⚠ **Только демо.** Никаких реальных денег до отдельного явного разрешения владельца счёта.

---

## 0. Предпосылки (проверь до начала)

1. **MT5-терминал установлен, запущен и залогинен в ДЕМО-счёт.** Автотрейдинг разрешён
   (кнопка «Algo Trading» включена).
2. **Python 3.10+**. Проверь: `python --version`.
3. Пакеты: `pip install MetaTrader5 pandas numpy pytest`.
4. Проверь связь Python↔MT5:
   ```python
   python -c "import MetaTrader5 as m; print(m.initialize(), m.account_info())"
   ```
   Должно вернуть `True` и объект счёта. Если `False` — MT5 не запущен/не залогинен или
   разрядность Python≠MT5. Не продолжай, пока не `True`.

---

## 1. Разложить файлы

Пакет `ai-trader-skillset/` (эта папка) переносишь на ПК трейдера, затем:

1. **Ядро** (`trader_lib/`, `scripts/`, `config/`) → в `~/.claude/trader-lib/`:
   ```powershell
   $dst = "$HOME\.claude\trader-lib"
   New-Item -ItemType Directory -Force $dst | Out-Null
   Copy-Item -Recurse -Force .\trader_lib, .\scripts, .\config $dst
   ```
2. **Скиллы** (6 шт.: пять трейдерских + директорский) → в `~/.claude/skills/`:
   ```powershell
   Copy-Item -Recurse -Force .\skills\* "$HOME\.claude\skills\"
   ```
3. **Loop-промт** → `~/.claude/skills/trader-loop/` (или подключи как тело `/loop`).

> Если скиллы ещё не собраны из плана (`docs/plan.md`) — сначала выполни план
> (Phase 0→6), он материализует `trader_lib/*`, `scripts/*` и 4 `SKILL.md` из
> `docs/skill_contents.md`. Порядок фаз строгий.

---

## 2. Настроить конфиг и зафиксировать стартовый баланс

1. Открой `~/.claude/trader-lib/config/trader.config.json`. Проверь:
   - `account.label` — метка счёта (папка стора будет `~/.claude/trader-state/<label>/`).
   - `risk`: дефолты 3%/6%/буфер0.3/K3/кап1% — **согласованы с владельцем счёта, не меняй без спроса.**
     Если у счёта правила конкретной prop-фирмы — подгони именно здесь.
   - `loop.cycle_seconds` — период цикла (по умолчанию 300 = 5 мин).
2. **Зафиксируй стартовый баланс** (baseline для общей стены −6%). Создай
   `~/.claude/trader-state/<label>/account_init.json`:
   ```powershell
   $sd = "$HOME\.claude\trader-state\demo-primary"; New-Item -ItemType Directory -Force $sd | Out-Null
   $bal = python -c "import MetaTrader5 as m; m.initialize(); print(m.account_info().balance)"
   Set-Content "$sd\account_init.json" ('{""initial_balance"": ' + $bal + '}')
   ```
   Это фиксирует базу для −6% один раз. Дневная база (−3%) считается автоматически от
   equity на старте серверного дня.

---

## 3. Проверка перед торговлей (ОБЯЗАТЕЛЬНА)

Никакой торговли, пока не пройдут все три.

1. **Юнит-тесты ядра** (офлайн, без live MT5):
   ```powershell
   cd "$HOME\.claude\trader-lib"; python -m pytest tests -q
   ```
   Ожидание: всё зелёное. **Особо важен property-тест** `test_loss_sequence_never_breaches_daily`
   — он доказывает, что никакая серия убытков не пробьёт дневную стену 3%. Красный
   property-тест = НЕ торговать.
2. **Смоук перцепции** (live):
   ```powershell
   python scripts\perceive.py --symbol XAUUSD --tf M5,H1
   ```
   Ожидание: JSON со снимком, `account.total_budget_remaining_pct ≈ 6`,
   `daily_budget_remaining_pct ≈ 3`. Если фичи `null` с reason «insufficient» — символ/ТФ
   без истории, возьми другой. Если ошибка MT5 — вернись к §0.
3. **Смоук гейта** (live):
   ```powershell
   python scripts\risk_gate_cli.py
   ```
   Ожидание: на свежем счёте `verdict: OK`, `max_risk_per_trade_usd` > 0. Искусственно
   проверь fail-closed: временно переименуй MT5 недоступным — вердикт должен стать
   `HALT_NEW` (никогда не `OK` при ошибке).

---

## 4. Интеграция в модель (включение цикла)

Трейдер работает непрерывным циклом. Подключение:

1. **Операционный промт.** Содержимое `trader-loop/loop_prompt.md` — это то, что модель
   выполняет каждый тик. Либо запусти как `/loop` с этим телом, либо помести в системную
   инструкцию сессии трейдера. Он кодирует строгий порядок:
   `perceive → close_watch → gate → recall → decide → score`, а `reflect` — раз в K сделок
   или в конце сессии.
2. **Скиллы подхватятся сами** по `description` (Claude Code сканирует `~/.claude/skills/`).
   Проверь, что видны: спроси модель «какие trader-* скиллы доступны» — должно быть 4.
3. **Ритм.** Между циклами — пауза `cycle_seconds`. Если используешь `/loop` — задай тот же
   интервал.
4. **Что модель делает сама, что делает код** (не путай):
   - Код (детерминированно, не переопределять): перцепция-фичи, риск-гейт, сайзинг, счёт.
   - Модель (свобода в рамках 4 рельсов): тезис, выбор сетапа, уверенность, entry/SL/TP,
     ведение позиции, рефлексия.

---

## 5. Первый запуск и холодный старт

- **Первые ~1–2 недели = фаза разведки, НЕ гонка за +10%.** Журнал пуст, `recall` отдаёт
  `insufficient` — это норма. Гейт держит риск малым. Задача модели — честно пробовать
  разные сетапы и логировать КАЖДОЕ осмысленное решение (вход и явный пропуск), чтобы
  наполнить журнал.
- **Переход в фазу давления на edge** — когда `scorecard.md` покажет 2–3 сетапа с
  плюсовым `avg_R`, `edge_significant: true` и n≥20. Тогда модель концентрирует размер на
  них. Переключение ведёт scorecard, не календарь.
- Стор растёт в `~/.claude/trader-state/<label>/`:
  `journal.jsonl` (правда), `stats.json` (выводимый), `playbook.md` (растит reflect),
  `scorecard.md` (твой надзор).

---

## 6. Надзор (для владельца счёта) и здоровье системы

- **Глянуть, работает ли:** открой `scorecard.md` — прогресс к цели, матожидание±edge,
  калибровка. Это ответ на «система реально хороша или везёт».
- **Инварианты, которые НИКОГДА не должны нарушаться** (если нарушены — стоп-разбор):
  - Реализованная дневная просадка не достигала 3%, общая — 6%.
  - У каждой открытой позиции есть SL.
  - Размер каждой сделки ≤ выданного гейтом `max_risk_per_trade_usd`.
  - При ошибке MT5 цикл пропускался, а не торговал вслепую.
- **Если MT5 отвалился** — перцепция вернёт ошибку, цикл сам пропустится. Восстанови
  терминал → цикл продолжит.
- **Ротация reflect:** playbook и stats обновляются автоматически на ритме; руками
  `stats.json` не редактируй (он выводимый, перезапишется).

- [ ] MT5 запущен, залогинен в ДЕМО, Algo Trading включён, `initialize()==True`.

## Команда трейдеров

Одиночный режим работает без единой правки — раздел нужен, только если
разворачиваешь отдел.

### Чем отличается от одиночки

| | Одиночка | Команда |
|---|---|---|
| состояние | `state_dir/` | + `state_dir/traders/<имя>/` на каждого |
| запуск | `session_start.py --model X` | `--trader <имя>` у каждой команды состояния |
| датчик | один | **тоже один**, читает алерты всех |
| мандаты | нет | `allocation.json`, пишет директор |

### Порядок дня

```powershell
# 1. Директор, до открытия
python scriptsootstrap_env.py --quiet      # общее: медианы, календарь, кластеры
python scripts\director.py scan              # числа по инструментам
#    → пишет allocation.json своим суждением
python scripts\director.py validate          # ненулевой код = мандаты не выданы

# 2. Каждый трейдер, своим процессом
$env:TRADER_ID = "trend"
python scripts\session_start.py --model <модель> --profile strong
#    → дальше по skills	rader-start\SKILL.md

# 3. Датчик — ОДИН на всех, запускается один раз
python scriptslert_watch.py

# 4. Закрытие
python scripts\director.py review            # числа всех трейдеров рядом
```

### Что держит команду от скучивания

Три проверки в гейте, не инструкции:

- **мандат** — вход вне выданного на день списка отклоняется;
- **кластер** — одна открытая позиция на корреляционный фактор, командой
  целиком. Семь валютных инструментов складываются в три фактора: EURUSD и
  USDCHF при −0.87 это один доллар, по символам не видно;
- **квота событий** — один трейдер не может выесть бюджет пробуждений
  остальных; критические условия проходят сквозь исчерпанную квоту всегда.

### Разворачиваешь не в Claude Code?

Читай `DEPLOY_AI.md` — там честно разобрано, что сломается в чужой среде.
Коротко: механизм пробуждения завязан на инструмент `Monitor`, и его придётся
заменить, не потеряв стоп-кран.
