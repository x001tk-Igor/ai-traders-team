# ai-traders-team

**Команда автономных ИИ-трейдеров** на Claude Code + MetaTrader 5: три
специализированных трейдера и директор-оркестратор, который не торгует.

Работает и как одиночный трейдер — команда выросла поверх него и ничего в нём
не сломала.

Модель выбирает тактику. Код держит риск. Эти две роли не пересекаются нигде — и
именно на этом шве построено всё остальное.

```
Стены:  −3% за день · −6% всего · обязательный стоп у каждой позиции
Цель:   +10% к балансу
Тестов: 967, все офлайн — торговая логика проверяется без терминала и без сети
```

---

## Чем это отличается от «бота с ИИ»

**Модель не крутится в цикле по таймеру.** Она спит, пока рынок не сделает того,
что она сама назвала заранее. Датчик `alert_watch.py` опрашивает рынок раз в
секунду и печатает строку при срабатывании; строка превращается в пробуждение.
Пока условие не выполнено — расход равен нулю.

Причина не в экономии ради экономии: подписки хватает примерно на 10–20
пробуждений в день, а не на 200 опросов. Цикл по таймеру сжигал бы недельный
лимит за сутки.

**Код не советует — код запрещает.** Предвходовой гейт из 12 проверок стоит на
единственном пути к ордеру. Обойти его нельзя: `enter.py` без гейта не работает
вовсе. Отказ каждой проверки — фраза, которую человек поймёт через месяц.

**Всё, что нельзя проверить, считается запретом.** Нет файла состояния — запрет.
Исключение внутри проверки — запрет. Незнание не равно разрешению.

## Команда трейдеров

Один трейдер превращается в отдел без потери контроля над риском: лимиты
остаются счётными, а не персональными.

| Роль | Механизм | Что раздаёт директор |
|---|---|---|
| Директор | не торгует | инструменты дня, доли бюджета, квоты событий |
| `trend` | продолжение по подтверждённому ADX | — |
| `fade` | фейд выноса на тонкой книге | — |
| `range` | границы диапазона | — |

**Механизм — постоянная специализация, а не сменная роль.** Статистика сетапа
копится по механизму, и ежедневная перетасовка не дала бы значимой выборки
никогда.

### Три болезни человеческих команд, вылеченные кодом

Все увидели одно движение и набросились на один инструмент; все встали в одну
сторону; встали друг против друга. Ни одна из трёх не лечится инструкцией —
инструкции нарушаются.

| Болезнь | Механизм |
|---|---|
| «торгуют всё что движется» | мандат дня: вход вне списка отклоняется гейтом |
| «все в одну сторону» | **корреляционные кластеры**: одна открытая позиция на фактор риска, командой целиком |
| «друг против друга» | тот же потолок: встречные внутри фактора тоже отклоняются |

Кластеры считаются из данных, а не назначаются. Замер на живом счёте показал,
что **семь валютных инструментов складываются в три независимых фактора**:
EURUSD и USDCHF при корреляции −0.87 — это один и тот же доллар, а по символам
это не видно.

**Директор работает до и после, а не во время.** Окно входа схлопывается за
секунды; оркестратор в пути исполнения ордера гарантированно терял бы входы.
Его решения компилируются в `allocation.json`, а исполняет их гейт — мгновенно и
без пробуждений.

## Устройство

| Путь | Что |
|---|---|
| `trader_lib/` | Ядро: гейт, риск, кластеры, мандаты, спред, новости, журнал, статистика |
| `scripts/` | Точки входа: восприятие, вход, выход, датчик, разбор, директор |
| `skills/` | Скиллы Claude Code: старт трейдера и директора, цикл решения |
| `docs/` | Дизайн, планы, схема алертов |
| `tests/` | 967 тестов, все офлайн |

Секретов в репозитории нет по устройству: доступы к терминалу и каналу
уведомлений живут в `state_dir` вне дерева проекта.

## Быстрый старт

```bash
python -m pytest -q                      # 967 тестов, без терминала и сети
python scripts/verify_install.py         # целостность развёртывания
python scripts/bootstrap_env.py --quiet  # среда: ok=false → торговля не стартует
```

| Документ | Кому |
|---|---|
| `DEPLOY.md` | человеку: развёртывание, одиночка и команда |
| `DEPLOY_CLAUDE.md` | агенту Claude Code на боевом ПК |
| `DEPLOY_AI.md` | **любой другой модели в чужой среде** — что там сломается и чем заменить |

## Что показала неделя живой работы

Контур торговал на демо-счёте пять дней. Прибыли не принёс — и это ожидаемо:
подтверждение сетапа требует выборки, которая за неделю не набирается.

Ценность оказалась в другом: **одиннадцать дефектов, найденных боем**, каждый
закрыт тестом-ловушкой на конкретный отказ. Четыре из них проявлялись только на
живом рынке и были невидимы для `--dry-run`.

Самый показательный класс — **«код написан, покрыт тестами и никем не
вызывается»**. Он встретился шесть раз, включая один случай в проверке,
написанной против него же. Отсюда отдельный вид тестов: сторож требует, чтобы
проверка присутствовала в конвейере, а не только существовала в модуле.

Второй по ценности вывод — методический. Во всех убыточных сделках, где модель
записывала в тезис оговорку **против собственного решения**, именно эта оговорка
и оказывалась причиной провала. Записанное сомнение — сигнал, а не формальность
для журнала.
