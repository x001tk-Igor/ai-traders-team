# Preflight — заполнить ДО первой сессии на новом ПК

Версия пакета: см. файл `VERSION` (сейчас **2.0.0**).

Этот чеклист заполняет **человек**, один раз на каждом ПК и после каждой смены
брокера, счёта или модели. Пока он не заполнен, торговать нельзя — не потому что
код запретит (часть пунктов он проверить не может), а потому что каждый пункт
здесь однажды уже был причиной неверного числа в расчёте риска.

---

## 1. Счёт

| Пункт | Значение | Как узнать |
|---|---|---|
| Валюта счёта | | `account_info().currency` |
| Стартовый эквити | | `account_info().equity` на момент старта |
| Тип счёта | | `account_info().trade_mode` (0=демо, 1=конкурс, 2=реал) |
| Максимальное плечо | | `account_info().leverage` |
| Логин / сервер | | `account_info().login`, `.server` |

> Предохранителя по типу счёта в коде НЕТ — решение владельца счёта от 2026-07-26. Риск-контур
> одинаков для демо и реала: стены 3%/6%, лимит одновременного риска, каскад по серии
> убытков, обязательный SL. Поле заполняется, чтобы в отчётах было видно, на каком
> счёте получены числа.

## 2. Среда

Запусти и приложи вывод:

```
python scripts/bootstrap_env.py
```

| Пункт | Значение | Комментарий |
|---|---|---|
| `trade_allowed` | | `false` → включи «Algo Trading» в терминале |
| Смещение сервера от UTC | | **обязано совпасть** с `risk.server_utc_offset_hours` в конфиге |
| Суффиксы символов | | `null` = чистые имена; иначе нормализация обязательна |
| Символы whitelist на месте | | отсутствующий символ блокирует старт |
| `spread` в барах заполнен | | если нет — медиана спреда набирается замерами |
| Второй процесс к терминалу | | датчик живёт отдельным процессом; `false` → его не запустить |
| Доступные макро-символы | | отсутствующие остаются `null`, гипотеза H5 не работает |

> ⚠️ Смещение сервера определяется по последнему тику и **не определяется при закрытом
> рынке** (в выходные последняя котировка пятничная). Запускай при открытом рынке.

## 4. Новости

| Пункт | Значение |
|---|---|
| Источник календаря | ForexFactory `ff_calendar_thisweek.xml` |
| Проверено, что фид парсится | `python -c "from trader_lib.news import *; print(len(parse_ff_xml(_fetch())))"` |
| Окна блокировки (обычное / топ) | из `news.normal_window_min` / `top_window_min` |
| Поведение при устаревшем кэше | `news.fail_mode` |

> Валюта события в реальном фиде лежит в теге `<country>`. Если в разобранных событиях
> валюты пустые — гейт новостей не заблокирует ничего; проверь это прежде, чем торговать.

## 6. Модель

| Пункт | Значение |
|---|---|
| Модель (`model.id`) | |
| Профиль (`model.profile`) | `strong` / `weak` |
| Приёмочный тест пройден | `python scripts/model_smoke.py` → результат |
| Дата приёмки | |

Профиль `weak` включает: риск ×0.5, только плановые входы, только подтверждённые
сетапы, dry-run по умолчанию. Ставится по результату приёмочного теста, а не по
впечатлению.

## 7. Подтверждение конституции

```
python scripts/constitution_ack.py            # посмотреть, что охраняется
python scripts/constitution_ack.py --ack --note "первый запуск на этом ПК"
```

Пока подтверждения нет, предвходовой гейт запрещает вход. Это не формальность:
подтверждая, ты заявляешь, что видел текущие лимиты и согласен с ними.

## 8. Последняя проверка перед запуском

- [ ] `python -m pytest` — всё зелёное (иначе стоп)
- [ ] `python scripts/bootstrap_env.py --quiet` → `ok: true`
- [ ] `python scripts/constitution_ack.py` → СОВПАДАЕТ
- [ ] `python scripts/brief.py` → раздел `orphans` пуст, `watchdog` жив
- [ ] `python scripts/enter.py --dry-run --draft <файл>` → решение без отправки
- [ ] датчик вооружён, `watch_heartbeat.json` обновляется, `ts` свежий
- [ ] за первый день пробуждений **не больше 25**
