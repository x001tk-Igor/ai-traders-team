# trader-start — открытие торговой сессии

Точка входа. Дальше всё ведёт `~/.claude/trader-lib/prompts/loop_prompt.md` —
этот скилл лишь доводит контур до состояния «датчик взведён» и передаёт
управление туда.

## 1. Объяви себя — первой командой, до всего остального

```
python ~/.claude/trader-lib/scripts/session_start.py --model <твоё имя> --profile <strong|weak>
```

**Подставь имя модели, которой ты являешься на самом деле** (`claude-opus-5`,
`claude-sonnet-5`, `qwen-max`…). Не из конфига и не из журнала: там имя
предыдущей модели, а конфиг переносится между ПК как есть. Ты единственная, кто
знает точно — Claude Code имя модели дочерним процессам не передаёт.

Этим именем подписывается каждая запись, по нему считается твоя калибровка. Две
модели в одном бакете портят статистику обеим, и разделить записи потом нечем.

**Профиль.** `strong` — полные права. `weak` (риск ×0.5, только плановые входы,
только подтверждённые сетапы) бери, если приёмочный тест
(`scripts/model_smoke.py`, см. `docs/model_acceptance.md`) на этой модели не
проходился. Занизить себе права безопасно, завысить — нет.

## 2. Проверь, что среда не врёт

```
python ~/.claude/trader-lib/scripts/bootstrap_env.py --quiet
```

`ok=false` → **торговля не стартует**. Прочитай `blocking`, скажи владельцу счёта, что
чинить, и остановись. Профиль блокирует ровно то, без чего числа врут: смещение
сервера (от него граница торгового дня и стена −3%), Algo Trading, символы.

## 3. Пойми, что было до тебя

```
python ~/.claude/trader-lib/scripts/brief.py --symbols XAUUSD
```

Смотри: `orphans` (позиции без записи в журнале — разбери до входов), `watchdog`
(жив ли датчик), `scorecard.calibration` — **твоя**, по объявленному имени.

Если калибровки по тебе нет («нет данных по этой модели»), это норма для первого
запуска на новой модели: чужую не бери, работай на голом суждении с малым риском.
`playbook.md` при этом читай — словесные выводы переносятся между моделями,
числовая калибровка нет.

## 4. Дальше — операционный цикл

Открой `~/.claude/trader-lib/prompts/loop_prompt.md` и работай по нему: план дня
→ вооружение датчика через Monitor **один раз за сессию** → работа по событиям →
на каждом пробуждении одна запись из трёх (вход / осознанный отказ / наблюдение)
→ в конце дня `review.py --save` и `trader-reflect`.

## Чего не делать на старте

- **Не правь `config/trader.config.json`.** Лимиты — решение владельца счёта; правка ломает
  хэш конституции и останавливает торговлю до его подтверждения. Это не баг.
- **Не подтверждай конституцию за человека** (`constitution_ack.py --ack`).
- **Не взводи датчик дважды.** Новые условия — переписать `alerts.json`, он
  подхватит сам; перезапуск теряет бюджет и очередь недоставленного.
